一个平台，接管日常运维

      
从一台主机到多个 Kubernetes 集群，从手工敲命令到流程化作业。

      

        

          

          
Web 终端

          
基于 xterm.js 的多标签终端：主题切换、全屏模式、会话保持。Linux 走 SSH，Windows 走 WinRM，同一个入口。

        

        

          

          
浏览器内 RDP

          
集成 Guacamole 网关，Windows 远程桌面直接在浏览器打开。零客户端安装，一次性令牌连接，更安全。

        

        

          

          
批量执行与脚本库

          
跨百台主机并发执行命令，结果按主机聚合比对；常用操作沉淀为脚本库，版本化、可复用、可审计。

        

        

          

          
监控与容量规划

          
CPU / 内存 / 磁盘指标采集，阈值告警实时推送；线性回归预测到达水位的天数，扩容不再靠拍脑袋。

        

        

          

          
Kubernetes 管理

          
多集群接入：工作负载伸缩、YAML 在线编辑、Helm 发布、Pod Shell 与实时日志、集群容量趋势。

        

        

          

          
应用与发布

          
应用目录与发布流程标准化：上传制品、目标主机、一键发布与回滚，发布记录全程可追溯。

        

        

          

          
计划任务

          
类 Cron 表达式调度，主机脚本与容器任务统一编排，执行历史与失败告警一目了然。

        

        

          

          
月度运营报告

          
自动汇总月度可用率、告警时间线、P1/P2 事件与容量红绿灯，运维价值一页呈现。

        

        

          

          
权限与安全

          
能力位权限模型 + 自定义角色，主机凭据 AES 加密存储，MFA 两步验证，操作全量审计。

        

      

    

  


  
  

    

      
为「简单部署」而生

      
一个后端二进制 + 一份 Docker Compose，没有 K8s 也能运维 K8s。

      

        

          后端
          
Go · Gin · GORM

          
单二进制内建调度器、WebSocket 网关与 SSH/WinRM 客户端，交叉编译覆盖 Linux / Windows / ARM。

        

        

          前端
          
Vue 3 · Element Plus · xterm.js

          
构建产物为纯静态文件，由后端直接托管；中英双语开箱即用。

        

        

          数据与交付
          
PostgreSQL · Docker Compose

          
结构自动迁移，密钥首次启动自动生成并持久化；Compose 一键拉起服务、数据库与 RDP 网关（guacd）。

企业级安全，开箱即用

      
权限、加密、认证、审计——四道防线默认开启。

      

        
凭据加密
主机账号密码与 kubeconfig 以 AES 加密落库；RDP 连接令牌一次性取用，用后即焚。

        
MFA 两步验证
TOTP 动态口令，用户自助开关，防止弱口令带来的横向风险。

        
LDAP 集成
对接企业域目录，账号免维护，显示名自动同步。

        
全量审计
登录、执行、发布、删除全部留痕，谁在什么时候动了哪台机器，一目了然。
