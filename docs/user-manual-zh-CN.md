## 1. 登录与账号安全

- 使用管理员分配的账号登录；如已启用 LDAP，也可用域账号登录。
- **修改密码**：右上角用户菜单 → 个人中心。
- **MFA 两步验证**：用户菜单 → MFA 安全 → 扫码绑定（Google/Microsoft Authenticator 均可）。绑定后每次登录需输入 6 位动态码。丢失设备可联系管理员重置。
- **语言/主题**：右上角切换中文/English、深色/浅色模式。

## 2. 界面导览

- 左侧为主菜单，按角色显示可见项；顶部为页面标题、每日寄语与用户菜单。
- **日志检索**菜单仅在管理员启用 OpenObserve 集成后出现。
- 所有列表页支持关键字筛选；大多数写操作有审计记录。

## 3. 主机管理

### 添加 Linux 主机
1. 主机 → 添加主机：填名称、IP、SSH 端口（默认 22）；
2. 认证方式选**密码**（填登录密码，保存后平台自动推送公钥切换为密钥认证）或**密钥**（选择已导入的 SSH 密钥）；
3. 保存后点「探活」确认连通。

### 添加 Windows 主机
- OS 类型选 Windows，填 WinRM 端口（默认 5985）与 RDP 端口（默认 3389）；
- 目标机需先以管理员执行一次性配置：`winrm quickconfig`；
- 域环境推荐启用 Kerberos（账号填 `user@域` 格式）；工作组机器建议配置 WinRM HTTPS（详见项目文档 Windows 章节）。

### 批量导入
主机 → 导入，粘贴 `名称,IP,端口,用户名,分组` 格式的多行文本，页面级"公共密码"统一填入，勾选自动配对。

### 分组与探活
- 分组管理中创建层级分组；
- 勾选主机点「探活」并发检测连通性。

## 4. OS 账号与凭据

每台主机可挂**多个 OS 账号**（如 root、appuser），标签区分用途，默认账号用于终端与执行。

- **批量添加账号**：主机账号页 → 批量添加 → 按主机组选择（含子组，组内主机自动并入目标列表）或直接勾选目标主机 → 从模板选择或手工填写 → 执行。表格中**勾选已有账号**再打开对话框，会自动载入这些账号供复用到其他主机。
- **从模板添加**：对话框顶部选择凭据模板，自动填入用户名/密码/标签。
- **密码轮换**：账号可开启定期轮换（周期/长度/复杂度可配），密码 AES-256 加密存储、永不显示；LDAP 账号自动跳过。
- **查看密码**：管理员可点「查看」（记审计）。
- **账号模板**：LDAP/域账号密码只需录入一次，添加主机或批量导入时引用。

## 5. Web 终端

主机资产树点选主机即开终端（仅 Linux/SSH；Windows 主机不提供终端，请使用 RDP）；支持多标签并发、按 OS 账号开多个会话、全屏切换。关闭标签页会话自动断开。

## 6. 批量执行与文件分发

- **批量执行**：作业执行 → 填命令或选脚本 → 树选主机/多 IP → 执行。每台主机实时流式输出，任务历史页可查汇总、导出 `.log`/CSV。
- **危险命令拦截**：命中危险规则（rm -rf 等）的命令会直接拒绝并记审计。
- **文件分发**：上传文件 → 选目标主机 → 并发 SFTP 分发，实时进度。

## 7. 脚本库与计划任务

- **脚本库**：保存常用脚本（支持参数），一键批量执行。
- **计划任务**：Cron 表达式定时在选定主机执行命令/脚本；可暂停/恢复/立即执行，历史留痕，可邮件通知。

## 8. 监控与告警

- **资源监控**：主机 CPU/内存/磁盘每分钟采集，进度条 + 趋势抽屉（6h/24h/7d/30d）；采样保留 30 天。
- **应用监控**：HTTP(s)/TCP/Ping 三类拨测，心跳条 + 24h 可用率 + 立即检测。
- **告警规则**：全局阈值（故障持续秒数、恢复通知开关）。
- **CMD 分级告警**：P1–P4 每级可设 CPU/内存/磁盘阈值、持续时长与通知通道。
- **维护窗口**：计划内停机不计可用率、不触发告警；页面实时显示当前是否处于维护窗口；变更留痕（「当前配置 / 历史版本」标记，管理员可删除单条或清空记录）。
- **AI 诊断**（管理员标签页）：disk/mem/cpu 告警触发后自动采集主机状态（Linux 走 SSH、Windows 走 WinRM）交由 AI 分析，全文推送该级别绑定通道；应用监控宕机时自动做服务端网络探测（DNS / TCP / HTTP 证书 / Ping），目标命中纳管主机时附加 SSH 采集，报告推送该监控器绑定通道。生效级别/指标、冷却分钟与诊断提示词均可配置；磁盘告警可执行管理员定义的受控清理命令（逐字执行、AI 不生成命令、全程审计）。
- **通知通道**：邮件/Webhook/企业微信/钉钉/飞书/Telegram，支持测试发送与模板编辑。

## 9. 日志检索

需管理员先启用 OpenObserve 集成（系统管理 → 可观测集成）。

- 左侧选数据流（主机指标/任务输出/告警事件/Windows 事件日志/数据库审计/自定义流）；
- 选时间范围（1h/24h/7d/30d 或自定义起止）；
- 支持直接写 SQL 查询，也可用快捷过滤（Windows 事件日志按类型/事件 ID/主机过滤）；
- 点击行首箭头展开完整字段；导出 CSV。

## 10. AI 能力

- **AI 助手**：右下角悬浮对话。可询问运维问题；每次提问都会自动附上**平台实时状态快照**（未恢复的告警事件、当前宕机的应用监控、离线主机），因此可以直接问「目前有哪些 active 的告警」这类问题；按当前所在页面自动感知模块上下文。诊断系统提示词可在 监控中心 → AI 诊断 中自定义。推理模型输出的 `<think>` 思维链会被自动剥离，不会出现在回复里。
- **告警诊断**（管理员启用后）：配置入口在 监控中心 → AI 诊断。主机告警自动采集状态（Linux 走 SSH、Windows 走 WinRM）交由 AI 分析，分析全文通过该级别绑定的通知通道推送；应用监控宕机自动做服务端网络探测并推送该监控器绑定的通道。
- **受控磁盘清理**（可选）：磁盘告警时按管理员预定义的命令目录逐字执行清理（AI 不参与命令生成），目录在 监控中心 → AI 诊断 中管理；仅 Linux 主机执行。

## 11. RDP 远程桌面

Windows 主机行点「RDP」在当前页打开浏览器内远程桌面（无需 mstsc；Windows 主机操作菜单只有 RDP，无终端）。桌面随窗口等比自适应缩放，远端分辨率跟随窗口大小调整；顶部「关闭」按钮断开会话并返回主机列表。依赖服务端 guacd + rdp-gateway 组件。凭据经一次性加密令牌换取，浏览器不接触明文。HTTPS 部署时流量经同源代理转发。

## 12. K8S 集群管理

- 添加集群：粘贴 kubeconfig 或 CA + 客户端证书三件套；证书有效期自动跟踪（30/7 天提醒）；
- 管理页覆盖节点、工作负载（Pod 日志/Shell/删除，Deployment 伸缩/重启）、服务发现、配置、存储、Helm 发布、访问控制；
- 所有资源支持 YAML 查看与编辑；容量规划提供 30d/1y 趋势与耗尽预测；运维月报可打印 PDF。

## 13. 应用与发布

- **应用管理**：定义应用（部署目录、制品名、启停命令、健康检查 URL、发布账号）并绑定主机；
- **发布中心**：上传制品 → 发布（停止 → 备份 → 上传 → 启动 → 健康检查）→ 失败一键回滚到最近备份。

## 14. 报表

- **采集报表**：内置模板（服务器账号、crontab、健康检查、系统信息、端口与证书）批量采集，结果可查可导出 `.log`/CSV；端口与证书报表检测 HTTPS 证书到期。
- **运营月报**：按月生成执行摘要 + 容量风险红绿灯 + 主机资源表 + K8S 表 + 告警统计 + 配置变更，打开标签页自动加载，支持打印导出 PDF 与告警明细 CSV。

## 15. 权限与安全

- **角色**：内置 admin/ops/publisher/viewer/auditor/k8s 六种 + 自定义角色（能力位矩阵：模块 × 操作）；菜单可见性按角色配置；
- **用户组**：绑定成员 + 主机分组 + OS 账号规则 + 应用，实现团队数据隔离；
- **API 密钥**：供外部系统调用 `/api/ext/*`（主机状态、监控、任务、批量执行、自定义数据推送）；
- **审计**：全量写操作留痕（谁/动作/资源/IP/状态），管理员与审计员可见；敏感字段打码。

## 16. 常见问题

**Q：页面一直跳登录？**
会话过期或后端重启导致令牌失效，重新登录即可；反复出现请检查浏览器是否禁用了 localStorage。

**Q：Windows 主机连接失败？**
确认目标机已执行 `winrm quickconfig`；域环境推荐 Kerberos；工作组机器建议配 WinRM HTTPS（详见项目文档）。

**Q：日志检索菜单不见了？**
OpenObserve 集成被停用。到 系统管理 → 可观测集成 重新启用即可。

**Q：告警没有生成 AI 分析？**
检查 AI 服务是否启用且可达、告警级别/指标是否在诊断范围内、是否处于冷却期（默认 30 分钟）。
