## 1. 系统简介

JNexus 面向中小团队的自托管运维场景，目标是**用一个网页接管日常运维**：

- **双平台主机**：Linux（SSH）与 Windows（WinRM / 浏览器内 RDP）统一管理；
- **多模块一体化**：资产（主机 / 数据库 / Web 应用）、账号凭证、批量执行、文件分发、脚本库、计划任务、监控告警、容量规划、K8S 管理、应用发布、采集报告、运营报表、日志检索、AI 告警诊断、Web 应用托管（PAM）、数据库工作台；
- **权限内建**：能力位权限模型 + 自定义角色 + MFA + LDAP + 全量审计；
- **AI 能力**：全站悬浮 AI 对话（兼容 OpenAI 协议）+ 告警自动诊断分析；
- **可观测集成**：OpenObserve 双写与日志检索（长期存储、全文检索、受控清理）；
- **部署简单**：单个二进制 + Docker Compose（含数据库、RDP 网关、可选 OpenObserve）；
- **中英双语 + 深浅色主题**：开箱即用。

适用规模：几台到几百台主机、1 到多个 Kubernetes 集群。

## 2. 系统架构

```
浏览器 (Vue 3 SPA)
   │  HTTP / WebSocket
JNexus Server（单二进制：API + 静态资源 + 调度器 + WS 网关）
   ├─ SSH / WinRM ──── Linux / Windows 主机
   ├─ Kubernetes API ─ 多个 K8S 集群
   ├─ guacamole-lite → guacd ─ Windows RDP 3389
   └─ GORM ─ PostgreSQL（业务数据、监控采样、审计）
```

- **后端**：Go 1.25；Gin 提供 API 与静态资源托管，GORM 管理数据模型与自动迁移；内建调度循环负责指标采集、采样归档、计划任务与告警评估。
- **前端**：Vue 3 + Element Plus + xterm.js，构建产物为纯静态文件由后端直接托管；中英双语内建。
- **RDP 网关**：`guacamole-lite`（Node.js）+ `guacd`（Apache Guacamole 1.6.0），浏览器经 WebSocket 连接网关，网关再连 Windows 3389；连接凭据通过**一次性令牌**换取，AES 加密传输。
- **部署形态**：Docker Compose（推荐，四服务：jnexus / postgres / guacd / rdp-gateway）或裸二进制 + 外部 PostgreSQL。

## 3. 快速开始

### Docker Compose（推荐）

```bash
git clone https://github.com/hmilyzhang/JNexus.git
cd JNexus/deploy
docker compose up -d
```

- 控制台地址：`http://<服务器IP>:8080`
- 默认管理员：`admin / admin123`（**首次登录后请立即修改**，见 [系统管理](#18-系统管理)）
- 数据库、表结构、加密密钥均由程序首次启动自动创建/生成。

### 裸二进制

1. 从 Releases 下载对应平台二进制（或 `go build ./cmd/server` 自行编译）；
2. 准备 PostgreSQL，并通过环境变量提供连接信息（见 [配置参考](#4-配置参考)）；
3. 运行二进制，默认监听 `:8080`。

### 添加第一台主机

登录后进入 **资产管理 → 主机** 页面：添加主机（IP、SSH 端口、root 账号或密钥）→ 状态变绿即可打开终端、执行命令、查看监控。Windows 主机选择 OS 类型为 Windows 并填写 WinRM 端口（默认 5985）。

## 4. 配置参考

JNexus 优先读取环境变量；首次启动自动生成的密钥会持久化到数据目录（容器内 `/app/data`），重启不丢失。

| 环境变量 | 说明 | 默认 |
| --- | --- | --- |
| `JNEXUS_DB_HOST` / `JNEXUS_DB_PORT` | PostgreSQL 地址 | `postgres` / `5432` |
| `JNEXUS_DB_USER` / `JNEXUS_DB_PASSWORD` / `JNEXUS_DB_NAME` | 数据库账号 | `jnexus` / `jnexus123` / `jnexus` |
| `JNEXUS_DSN` | 完整 DSN（设置后忽略以上 DB 变量） | - |
| `JNEXUS_AES_KEY` | 凭据加密主密钥（32 字符）；不设置则自动生成 | 自动生成 |
| `JNEXUS_JWT_SECRET` | JWT 签名密钥；不设置则自动生成 | 自动生成 |
| `JNEXUS_DATA_DIR` | 密钥/数据持久化目录（容器内默认 `/app/data`） | `/app/data` |
| `JNEXUS_VERSION` | 版本号注入（构建参数 `APP_VERSION`） | 开发版 |
| `SSL_CERT_FILE` | 容器内自动生成合并 CA bundle 后设置，无需手动配置 | 自动 |
| 服务端口 | 固定监听 `:8080`（Compose 已映射） | `8080` |
| `./cacerts/` | Compose 挂载主机 CA 证书目录（`.crt`/`.pem`），入口自动合并进容器信任 | 可选 |

**密钥安全**：`JNEXUS_AES_KEY` 用于加密所有主机凭据，一旦丢失已加密数据无法解密。容器入口脚本会将其保存到数据卷的 `aes_key` 文件；请定期备份数据卷。

## 5. 主机管理

**菜单：资产管理 → 主机**

- **统一资产入口**：资产管理页以页签整合**主机 / 数据库 / Web 应用**三类资产，「新增资产」统一下发；
- **分组树**：多级主机组，主机可归组，支持按组筛选；工具栏支持**批量移动分组**；
- **主机字段**：名称、IP、SSH 端口、OS 类型（Linux / Windows）、描述、所属分组；
- **OS 账号**：一台主机可挂多个账号（密码或密钥），标记默认账号；执行/终端/发布按"指定账号 → 主机默认账号"的顺序取用；集中管理见 [账号凭证](#6-账号凭证)；
- **凭据模板**：批量添加主机时套用统一账号模板；
- **Windows 支持**：OS 类型选 Windows 后走 WinRM（默认端口 5985，支持 NTLM 域账号），可执行 PowerShell、采集指标；RDP 支持多账号登录选择器（`DOMAIN\user` 与 UPN 均可）；
- **级联删除**：删除主机（单台或批量）自动清理其 OS 账号；
- **云资产同步**：从 AWS / Azure / 华为云发现并导入云主机（见 [云资产同步](#25-云资产同步aws--azure--华为云)）；
- **主机操作**：测试连接、打开终端、文件分发、容量规划抽屉、批量删除。

## 6. 账号凭证

**菜单：账号凭证**

- 全部主机 OS 账号集中管理：按主机 / 关键字 / 轮换状态筛选，添加 / 编辑 / 轮换 / 查看（管理员可查密码，记审计）；
- **密码自动轮换**：按账号开启并配置周期，随机强密码 AES 加密落库、不明文展示；普通账号经同主机 root/NOPASSWD sudo **特权链**完成轮换；配对密钥账号（留存密码）经密钥登录轮换；LDAP/域账号自动检测跳过；
- **密码历史**：每次轮换自动留存（每账号最近 24 条），管理员可查、全程审计；
- **账号模板**：一次性录入 LDAP/AD 密码，添加主机或批量导入时复用；
- 主机密码、私钥、kubeconfig 等敏感信息一律 **AES 加密落库**，界面不回显明文；
- 批量添加 / 删除带引用保护。

## 7. Web 终端

**菜单：任务 → Web 终端**

- 左侧资产树（分组 → 主机 → OS 账号），点击即开终端，多标签并行；
- xterm.js 渲染：**6 款主题**（默认 Dark、Dracula、One Dark、Solarized Dark/Light、GitHub Light）、**页面内全屏**、自适应尺寸；
- 终端会话经 WebSocket 直连后端 SSH 通道，会话随页面保持（工作区仅列 Linux 主机；Windows 走 RDP）；
- K8S Pod Shell 与主机终端同一套体验（见 [Kubernetes 管理](#14-kubernetes-管理)）。

## 8. 浏览器内 RDP

**前置**：Windows 主机开启远程桌面（3389）；Compose 已捆绑 `guacd 1.6.0` 与 `rdp-gateway`。

- 主机列表点击 **RDP**：后端生成一次性连接令牌（5 分钟有效、用后即焚），新窗口打开纯浏览器远程桌面；
- 令牌经 AES 加密的查询串传递，网关回调换取真实凭据，数据库中不留连接明文；
- 支持分辨率/分辨率自适应与剪贴板（依 guacd 能力）。

## 9. 批量执行与文件分发

**菜单：任务 → 命令执行 / 文件分发**

- **命令执行**：选择多台主机（分组勾选）并发执行 Shell / PowerShell，超时可控；结果按主机聚合展示（退出码 + 输出），可全选复制为报告；
- 执行采用主机默认 OS 账号，可指定凭据；
- **文件分发**：上传文件批量分发到目标主机指定路径，分发结果逐台可见；
- 所有执行/分发记录进入 **任务记录**，可导出 CSV 审计。

## 10. 脚本库

**菜单：任务 → 脚本**

- 常用操作沉淀为脚本：名称、描述、语言（Shell / PowerShell）、内容；
- 支持脚本参数模板；从执行页一键选用；
- 脚本可被计划任务引用，实现周期化作业。

## 11. 计划任务

**菜单：计划任务**

- 标准 Cron 表达式调度（秒级可选），到点自动在目标主机执行脚本/命令；
- 每次执行记录状态、耗时与输出，失败可配置告警；
- 支持手动"立即执行"、启用/停用、编辑重排。

## 12. 监控与告警

**菜单：监控中心**

- **指标采集**：调度器按间隔采集主机 CPU / 内存 / 磁盘（Linux 经 SSH，Windows 经 WinRM），原始样本保留 30 天，之后自动归档为小时聚合（支持 180 天 / 1 年视图）；
- **趋势视图**：单主机 6h / 24h / 7d / 30d / 180d / 1y 曲线；
- **可用率**：结合维护窗口计算 24h / 30d 可用率，窗口内故障不计入；
- **告警规则**：CPU / 内存 / 磁盘阈值实时评估，支持恢复通知开关；主机重启（boot id / 启动时间变化）自动告警；
- **告警通道**：邮件 / Webhook / 企业微信 / 钉钉 / 飞书 / Telegram，在系统设置配置 SMTP 与通道后按规则绑定；
- **监控项**：HTTP / TCP / Ping 拨测，监控可用率与响应时间。

## 13. 容量规划

- **主机维度**：容量抽屉展示 CPU / 内存 / 磁盘历史 + 线性回归预测"到达 90% 水位还需 N 天"，红黄绿分级；
- **K8S 维度**：集群级 CPU / 内存容量趋势（15 分钟采样，≤48h 原始点 / 7d·30d 小时桶 / 180d·1y 天桶），预测到达容量上限的天数；Pod 级用量趋势（Top10 采样）；
- 图表组件统一：Y 轴百分比 / 自适应量纲、网格线、时间轴、悬浮数值。

## 14. Kubernetes 管理

**菜单：K8S**

- **多集群**：以 kubeconfig 或 CA + 客户端证书接入多个集群；集群成员机制可把集群授权给不同用户（admin / user / viewer）；
- **资源管理**：Nodes / Namespaces / Deployments / StatefulSets / DaemonSets / Jobs / CronJobs / Pods / Services / Ingresses / ConfigMaps / Secrets / ServiceAccounts 全列表，自定义显示列、搜索、批量删除；
- **操作**：工作负载伸缩与重启、Pod 删除、CronJob 挂起/恢复、YAML 在线查看/编辑/下载、YAML 创建资源；
- **Pod Shell / 日志**：浏览器内交互式终端（tty）、实时日志跟随、集群 Shell（临时 busybox Pod，关闭自动清理）；
- **Helm**：Chart 仓库浏览与 Release 安装、升级、回滚、卸载；
- **容量规划**：集群与 Pod 级用量趋势与预测（见上节）。

## 15. 应用与发布

**菜单：应用 / 发布**

- **应用**：定义应用并登记目标主机；每台主机一份部署配置——部署目录、制品名、停止命令（为空则按进程名 kill）、启动命令、备份目录（默认 `部署目录/backup`）、发布用 OS 账号（不填用主机默认账号）；
- **发布流水线**：上传制品包 → 选择应用与目标主机 → 逐台执行 **停止 → 备份 → 上传 → 启动** 四步，每步实时输出、单步失败即停；
- **危险命令拦截**：发布各步命令内置危险命令检查，命中即拒执行；
- **回滚**：一键回滚（利用发布时备份快速恢复）；
- 发布历史完整保留，逐步输出可追溯。

## 16. 运营报表

**菜单：报表**

- **月度运营报告**：自动汇总当月 —— 可用率、告警次数与 P1/P2 时间线、容量红绿灯、执行统计；
- **报表详情**：可折叠列表展示检查项，仅展开失败项，方便汇报；
- **导出**：任务记录与报表支持导出，直接用于月度汇报。

## 17. 权限与安全

- **角色**：内置 `admin / ops / publisher / viewer / auditor`，并支持**自定义角色**；
- **能力位权限模型**：14 个模块 × 各自动作（如 `hosts.view`、`exec.exec`、`releases.rollback`、`ai.chat`），在"角色设置"里按模块勾选，路由与菜单双层生效；
- **MFA**：TOTP 两步验证，用户自助在个人中心开启；
- **LDAP**：对接企业目录登录，显示名自动同步；
- **审计**：登录、执行、发布、删除、K8S 操作全量写入审计日志，含操作者、IP、资源与结果；
- **加密**：主机凭据 / kubeconfig AES 加密存储；RDP 令牌一次性；JWT 会话签名。
- **AI 安全（Security by Design）**：
  - AI 聊天按能力位 `ai.chat` 授权（默认 admin/ops/publisher/k8s，只读/审计排除），前端入口与后端路由双层校验；
  - 聊天接口每用户限流 30 次/小时，防成本滥用；
  - 提示词注入防护：注入提示词的实时状态与机器采集数据（SSH/WinRM/网络探测）以 `UNTRUSTED` 标记包裹，系统提示词附加最高优先级安全规则（数据块内指令不可信、不泄露提示词与凭据、拒绝越权请求）；
  - 实时状态快照按用户主机权限过滤，无权限主机仅显示数量；
  - AI 永不直接执行命令：告警清理命令逐字来自管理员目录（禁止 `;&|`），聊天提问经审计中间件留痕。

## 18. 系统管理

**菜单：系统管理**

- **用户**：创建/禁用用户、重置密码、分配角色；
- **角色设置**：内置与自定义角色的菜单 + 能力位矩阵配置；
- **审计日志**：全量操作检索；
- **系统设置**：系统名称等全局参数；
- **危险操作**：敏感维护动作集中管控；
- **首次加固清单**：修改 admin 密码 → 开启 MFA → 建普通用户 → 按需配置 LDAP。

## 19. 升级与数据

- **升级**：`git pull && cd deploy && docker compose up -d --build`；表结构自动迁移，无需手工 SQL；
- **数据**：所有业务数据在 PostgreSQL；Compose 数据卷 `pgdata`（数据库）、`data`（密钥）、`uploads`（制品/上传）；
- **备份建议**：定期 `pg_dump` + 备份 `data` 卷（保住 AES 密钥即保住凭据可解密性）；
- **外部数据库**：设置 `JNEXUS_DB_*` 或 `JNEXUS_DSN` 后 `docker compose up -d jnexus` 单独起服务。

## 20. 常见问题

**Q：忘记 admin 密码？**
使用超级管理员所在数据库直接重置，或删除该用户后由其他 admin 重建；也可联系具备数据库访问权限的管理员将密码哈希替换为已知值。

**Q：Windows 主机连接失败？**
确认目标开启 WinRM（`winrm quickconfig`）、防火墙放行 5985；域账号使用 `DOMAIN\user` 格式。

**Q：RDP 打不开？**
检查 3389 可达、`guacd` / `rdp-gateway` 容器正常运行；连接令牌 5 分钟有效，超时请重新发起。

**Q：K8S 集群添加后部分资源为空？**
检查所用凭据的 RBAC 是否覆盖对应资源与命名空间；容量规划需要 metrics-server 或允许采样账号读取 metrics。

**Q：监控曲线没有数据？**
确认主机在线且凭据可用；采样间隔由调度器控制，新添加主机约需 1-2 个采样周期出图。

## 21. 可观测集成（OpenObserve）

JNexus 可选集成开源可观测平台 [OpenObserve](https://openobserve.ai)（AGPL-3.0，仅 HTTP 调用、无许可证传染），实现**长期存储与全文检索**：

- **五类内置数据流（双写）**：主机指标（`host_metrics`）、任务执行输出（`task_logs`）、告警事件（`alert_events`）、Windows 事件日志（`windows_events`）、数据库审计流水（`db_audit`）——每条独立开关；
- **日志检索菜单**：流选择器（内置流 + 自定义流自动发现）、SQL 查询、1h/24h/7d/30d + 自定义时间、分页（50–500/页）、事件 ID/主机/日志类型快捷过滤、CSV 导出；
- **可观测集成管理页**（系统管理）：连接健康与延迟探测、流级开关 + 推送统计（已推送/失败/最近推送/错误）、推送测试工具、外部推送 API（`POST /api/ext/oo/{stream}`，API 密钥认证）；
- **部署**：`docker compose --profile observability up -d --build`（单容器，默认关闭）；
- **菜单显隐**：集成停用时日志检索菜单自动隐藏；
- **凭证管理**：OpenObserve 凭据仅存于 JNexus（AES-256 加密），终端用户不接触 OpenObserve 界面，账号体系 100% 由 JNexus 管理。

## 22. AI 告警诊断与受控清理

disk/mem/cpu 阈值告警触发后，自动执行**AI 诊断流水线**：

1. **采集**：Linux 主机通过 SSH、Windows 主机通过 WinRM 运行固定只读诊断脚本（资源水位 / 进程榜 / 目录占用等）；
   - **应用监控**（HTTP/TCP/Ping）宕机时改做服务端网络探测：DNS 解析、TCP 连通、HTTP 重探测（状态码 / 延迟 / TLS 证书有效期 / 响应片段）、系统 Ping（目标经正则校验）；目标解析 IP 命中纳管 Linux 主机时追加 SSH 采集，区分服务故障与系统故障；
2. **分析**：告警上下文 + 诊断输出发给 AI（系统提示词可在界面自定义），返回根因分析/可疑进程/处置建议；
3. **推送**：主机告警分析全文通过该级别绑定的通知通道发送，应用监控诊断报告推送该监控器绑定的通道；同步写审计事件与 OpenObserve 流；
4. **受控清理**（仅磁盘告警）：按管理员预定义的**清理命令目录**逐字执行（如 /tmp 7 天未访问文件清理、journald 压缩），每条 60 秒超时保护，执行结果随报告推送。

**安全护栏**：
- AI 全程只输出分析文本，**不生成、不修改任何命令**；清理命令逐字来自管理员预定义目录；
- 仅磁盘告警触发清理；仅 Linux 主机执行清理；诊断配置入口在 监控中心 → AI 诊断（管理员）；每主机/每监控器冷却期（默认 30 分钟，共用配置）；
- 清理目录仅管理员可改；命令禁止 `; & |` 和换行；
- 诊断系统提示词可自定义（留空用内置默认）。

## 23. Windows 域环境接入

- **Kerberos 认证**（域环境推荐，CIS 合规）：主机级开关；账号使用 `user@REALM` 格式（Realm 自动取 UPN 后缀或系统配置 `winrm_krb5_realm`）；经 WinRM HTTPS + gokrb5 运行——不用 Basic、不用 NTLM、目标机无需放开 UAC 过滤；服务器需能读取 `krb5.conf`（配置 `winrm_krb5_config`）。
- **HTTPS + Basic**（工作组机器）：目标机配置 WinRM HTTPS 监听（5986）+ 自签证书后，JNexus 自动探测并切换 Basic over TLS——不受 NTLM 硬化策略影响。
- **NTLM**（传统/域内直连）：HTTP 5985 回退通道，本地/域账号皆可。

## 24. 反向代理部署（HTTPS + WebSocket）

通过反向代理（nginx 等）以 HTTPS 对外提供 JNexus 时，代理**必须转发 WebSocket 升级**——Web 终端、任务实时输出、日志跟随、RDP 网关代理（`/rdp-gw`）均使用 WebSocket：

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto https;
    proxy_read_timeout 3600s;
}
```

缺少 Upgrade/Connection 转发时，登录与页面正常，但终端/RDP/实时输出会立即断开。`X-Forwarded-Proto https` 告知 JNexus 当前为 HTTPS（影响 RDP 网关地址推导）。

## 25. 云资产同步（AWS / Azure / 华为云）

**入口：资产管理 → 主机 → 云资产同步**

- **云账号**：登记 AK/SK（AWS / 华为云）或服务主体（Azure），按账号选择区域，凭据 AES 加密落库；
- **自动发现**：拉取云主机实例并导入为主机资产，按**标签自动分组**；同 IP 已纳管主机不重复导入；
- **定时同步**：每账号可配同步间隔，由调度器自动执行；云端已释放的实例同步后自动下线；
- **账号模板**：云账号可绑定一个账号模板，导入的主机自动创建模板指定的 OS 账号（标记默认，密码取模板）——同步完即可执行/开终端；重复同步不重复建号；
- 全程写审计日志。

## 26. Web 应用托管（PAM）

**菜单：Web 应用**

- 托管常用 Web 管理台（地址 + 用户名/密码，AES-256-GCM 加密存储，界面不回显）；
- 点击「打开」：服务器启动**无头浏览器会话**，自动填入托管账密并完成登录，页面实时串流到浏览器，鼠标 / 滚轮 / 键盘直接操作；

## 27. 数据库工作台

**入口：资产管理 → 数据库**

- **数据库源**：注册 MySQL / SQL Server / PostgreSQL 实例（凭据 AES 加密，与 OpenObserve 采集共用连接信息）；每源可登记**多个账号**并按用户组授权使用（如监控用只读、DBA 用读写）；
- **SQL 编辑器**：CodeMirror 6，**schema 感知补全**（表 / 列 / 关键字，表结构 5 分钟缓存）、语法高亮、Ctrl+Enter 执行、深浅色主题自适应；
- **结果网格**：行号、列类型徽标、数值右对齐、NULL 弱化显示、CSV 导出；
- **安全护栏**：每源可开**只读模式**；危险 SQL（DROP/TRUNCATE、无 WHERE 的 UPDATE/DELETE 等）拦截确认；语句超时与返回行数上限；**每条语句全量审计**（语句、账号、来源 IP、耗时、行数）。

## 28. 采集报告

**菜单：报表 → 采集报告**

- **预设模板**：服务器账号、crontab 列表、健康检查、系统信息、端口&证书（监听端口、HTTP/HTTPS 协议识别、HTTPS 下发证书与本地证书文件到期检测）；
