AutoOps API 文档 / API Reference

认证

Authentication

所有端点位于 /api/ext/*，需携带 API 密钥（格式 aok_<keyID>.<secret>）。密钥由管理员在 系统设置 → API 密钥 创建，以属主用户身份调用（继承其角色与数据权限），仅创建时展示一次。

All endpoints live under /api/ext/* and require an API key (aok_<keyID>.<secret>). Keys are created by an admin under System Settings → API Keys and calls run as the owner user (inheriting its role and data permissions). The full key is shown only once at creation.

curl -H "Authorization: Bearer aok_xxx.yyy" http://server:8080/api/ext/hosts

安全限制：密钥仅存哈希、可选过期时间与 IP 白名单、每密钥限流 120 次/分钟（超限 429）、全部调用写入审计；密钥无法访问用户管理 / 系统设置 / 密钥管理接口。

Security: keys are stored as SHA-256 hashes only; optional expiry and IP allowlist; per-key rate limit 120 req/min (HTTP 429 beyond); every call is audited; keys cannot access user management, system settings or key management endpoints.

GET /hosts — 主机清单

GET /hosts — host inventory

GET /api/ext/hosts
{
  "ok": true,
  "data": [
    {
      "id": 7, "name": "web-01", "ip": "10.0.0.8", "port": 22,
      "status": "online", "group": "prod",
      "cpu": 23.9, "mem": 41.2, "disk": 63.5,
      "metrics_at": "2026-09-05T13:30:00+08:00"
    }
  ]
}

cpu/mem/disk 仅在 Linux 主机开启资源采集后返回；属主无权查看的主机不会出现。

cpu/mem/disk appear only for Linux hosts with resource collection enabled; hosts invisible to the owner are omitted.

GET /monitors — 应用监控

GET /monitors — application monitors

{
  "ok": true,
  "data": [

      "target": "https://portal.example.com",
      "enabled": true, "status": "up", "resp_ms": 66,
      "last_checked_at": "2026-09-05T13:31:20+08:00",
      "uptime_24h": 99.8
    }
  ]
}

GET /tasks/:id — 任务结果

GET /tasks/:id — task result

admin/auditor 属主可查全部任务；其他属主仅能查自己创建的任务。

admin/auditor owners see every task; other owners only tasks they created.

{
  "ok": true,
  "data": {
    "id": 42, "type": "command", "operator": "ops1", "status": "done",
    "results": [
      { "host": "web-01", "ip": "10.0.0.8", "account": "root",
        "status": "success", "exit_code": 0, "output": "..." }
    ]
  }
}

POST /exec — 执行命令（异步）

POST /exec — run a command (async)

属主需 admin/ops 角色；wait: true 最长等待 120 秒直接返回结果，否则仅返回任务 ID。

Owner must be admin/ops; wait: true blocks up to 120 s and returns results, otherwise only the task id.

POST /api/ext/exec
{
  "host_ids": [7, 8],
  "command": "df -hP /",
  "timeout_sec": 60,
  "wait": true
}
{
  "ok": true,
  "data": {
    "task_id": 43, "status": "done",
    "results": [
      { "host": "web-01", "ip": "10.0.0.8", "status": "success",
        "exit_code": 0, "output": "..." }
    ]
  }
}

错误码

Errors

HTTP含义Meaning
401密钥缺失/无效/停用/过期、IP 不在白名单，或误用登录令牌Missing/invalid/disabled/expired key, IP not allowed, or a login JWT used instead of a key
403属主权限不足Owner permissions insufficient
404资源不存在或不可见Resource not found or not visible
429超过限流（120 次/分钟）Rate limit exceeded (120 req/min)

Python 示例

Python example

import requests

BASE = "http://server:8080/api/ext"
HDRS = {"Authorization": "Bearer aok_xxx.yyy"}

hosts = requests.get(f"{BASE}/hosts", headers=HDRS).json()["data"]
down = [m for m in requests.get(f"{BASE}/monitors", headers=HDRS).json()["data"]
        if m["status"] == "down"]

r = requests.post(f"{BASE}/exec", headers=HDRS,
                  json={"host_ids": [h["id"] for h in hosts
                                      if h["name"] == "web-01"],
                        "command": "systemctl status nginx", "wait": True})
print(r.json()["data"]["status"])
